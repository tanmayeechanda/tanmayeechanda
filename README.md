## 📌 Featured Projects

### 🌐 [NetPulse](https://github.com/tanmayeechanda/netpulse) — Real-Time Network Topology Visualizer
> See your network. Understand your traffic.

Built with **FastAPI + React + D3.js + Docker**. Discovers devices on your local network, visualizes live traffic, runs traceroutes on a world map, and scans ports — all in a dark-mode dashboard.

---

### 🔑 [MiniRedis](https://github.com/tanmayeechanda/MiniRedis) — In-Memory Key-Value Store
> Redis from scratch in C++.

Built a Redis-inspired server using **C++17, TCP sockets, multithreading**, a custom thread pool, RESP protocol parsing, and append-only file persistence.

---

### ✂️ [TokenTrim](https://github.com/tanmayeechanda/TrimToken) — Code Context Compression Platform
> Less noise. More signal for your AI workflows.

A code-processing platform using **semantic chunking, Huffman coding, and hash-based deduplication**, built with React + TypeScript + FastAPI.

---

### 📱 [GenDevize](https://github.com/tanmayeechanda/GenDevize) — QR-Based Device Management System
> Track every device. Control every role.

Full-stack MERN platform with QR generation, JWT authentication, role-based access control (Super Admin / Admin / User), and device tracking.
